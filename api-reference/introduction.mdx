The Lucent ingest API is a small, CORS‑enabled HTTP surface that the
[`@lucenthq/sdk`](/sdk/installation) package talks to in production. You can
also call it directly from your own instrumentation — for example, a native
mobile app that already speaks rrweb, or a server‑side relay.

## Base URL

```text
https://batch-jobs-lucent.onrender.com
```

All endpoints are relative to this base URL. If you self‑host the ingest
service, point the SDK at your own base URL via the `ingestBaseUrl` option.

## Endpoints

| Method | Path | Purpose |
| ------ | ---- | ------- |
| `POST` | `/api/sdk/init` | Fetch runtime configuration for a key (sampling, flush interval, batch limits). |
| `POST` | `/api/sdk/replay` | Submit a batch of rrweb events for a session. |

See [Init](/api-reference/endpoint/init) and [Replay](/api-reference/endpoint/replay)
for the full request and response schemas.

## Authentication

Every request is authenticated with a `luc_pk_` public key. See the
[Authentication](/api-reference/authentication) page for full details on the
header format, query‑parameter fallback, error responses, and rate limits.

## Content encoding

Replay batches can be large. The `/api/sdk/replay` endpoint accepts either
plain JSON or gzip‑compressed JSON — set `Content-Encoding: gzip` on the
request and the server will decompress the body before parsing.
